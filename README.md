# CodeAlpha_Python_Internship
Task 1 – Hangman Game
A simple text-based Hangman game developed using Python as part of my CodeAlpha Python Programming Internship – Task 1.
The player has to guess the hidden word one letter at a time. The player gets a maximum of 6 wrong guesses before the game ends.

🛠️ Technologies Used
Python
random module
✨ Features
-Randomly selects a word from a predefined list
-Allows the player to guess one letter at a time
-Displays correctly guessed letters
-Tracks wrong guesses
-Prevents repeated guesses
-Maximum 6 wrong guesses allowed
-Displays You Won! when the word is guessed
-Displays Game Over! when all attempts are used
